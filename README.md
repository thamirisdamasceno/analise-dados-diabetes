## Sobre o projeto

Este projeto tem como objetivo realizar uma análise exploratória de dados para investigar a relação entre o Índice de Massa Corporal (IMC) e a ocorrência de diabetes.

A análise utiliza Python para explorar os dados, identificar padrões e compreender possíveis associações entre as variáveis.

## Objetivos

- Explorar e compreender a base de dados.
- Realizar o tratamento de valores ausentes ou inconsistentes.
- Analisar a distribuição do IMC.
- Investigar a relação entre IMC e diagnóstico de diabetes.
- Apresentar os resultados por meio de visualizações e conclusões baseadas nos dados.

## Ferramentas e tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Etapas da análise

1. Carregamento e exploração dos dados.
2. Limpeza e preparação da base.
3. Análise exploratória das variáveis.
4. Criação de visualizações.
5. Interpretação dos resultados.

## Fonte dos dados

Base de dados Pima Indians Diabetes Database, disponibilizada no Kaggle.
